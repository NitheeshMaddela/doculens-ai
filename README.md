# DocuLens AI

DocuLens AI is a private local workspace for searching text-readable PDFs and verifying answers against their source pages. Upload your own PDF or load five synthetic samples. The default provider uses local lexical retrieval and extractive answers, so you can run the demo without a model API key.

## Run locally

You need Docker with Compose v2.24 or later and free local ports 3000 (web), 8000 (API), and 5434 (PostgreSQL). Run these commands from the repository root. If you already have a `.env` file, keep it and skip the copy.

```sh
cp .env.example .env
docker compose up --build -d --wait
curl --fail --retry 10 --retry-connrefused http://127.0.0.1:8000/api/v1/ready
```

1. Open [the workspace](http://127.0.0.1:3000) and enter your `DEMO_ACCESS_KEY`. The example key is `doculens-local`.
2. Select **Load synthetic samples** and wait for `cancellation-policy.pdf` to show **Indexed**.
3. Select that PDF in **Document scope** and ask **What is the cancellation notice period?** Open the citation to page 2 to verify the 14-day notice period.
4. Ask **What is the payroll tax ID?** to see the insufficient-evidence response. Select **Search passages** to browse retrieved excerpts directly.

Next.js provides the workspace. FastAPI handles uploads, workspace authorization, retrieval, and citation validation. A separate worker extracts text by PDF page and stores passage embeddings in PostgreSQL with pgvector. API documentation is available at [localhost:8000/docs](http://127.0.0.1:8000/docs).

## Configuration

Set upload limits, page limits, query quotas, and provider settings in `.env`. The defaults are in [.env.example](.env.example).

To opt into hosted embeddings and answer generation, set `PROVIDER=openai`, `OPENAI_API_KEY`, `EMBEDDING_MODEL`, and `ANSWER_MODEL`. Apply the settings with `docker compose up -d --wait api worker`. If the embedding profile changes, delete and re-upload existing PDFs to make them searchable under the new profile. In hosted mode, the provider receives the question and authorized excerpts used for the answer. The bundled evaluation covers local mode.

## Development

Install Python 3.12+, uv, Node.js 22+, and GNU Make. Keep the Compose stack running for integration and browser tests.

```sh
uv sync --locked
npm --prefix apps/web ci
(cd apps/web && npx playwright install chromium)
make lint typecheck test
make e2e
```

If you changed the demo key, pass the same `DEMO_ACCESS_KEY` to `make e2e`. If you changed the web port, set `DOCULENS_WEB` to the workspace URL.

For integration tests, create a disposable database once and point the suite at it. The suite applies and rolls back migrations in that database. If you changed the database port or password, update the connection URL.

```sh
docker compose exec -T db createdb -U doculens doculens_test
TEST_DATABASE_URL=postgresql+psycopg://doculens:doculens-local@127.0.0.1:5434/doculens_test make integration-test
```

Use `make contracts` to regenerate OpenAPI and TypeScript types after changing the API. Use `make fixtures` to regenerate the sample PDFs.

## Evaluation

Open **Evaluation** in the workspace to view the bundled measurements. The included local-provider run covers 33 synthetic questions and uses a literal fact and citation rubric. See the run metadata and per-question results in the [bundled report](reports/evaluation.json).

To reproduce the run with the default provider, temporarily raise the local query quota. The evaluator calls the API on port 8000 by default. If you changed the port, set `DOCULENS_API` to the API base URL including `/api/v1`.

```sh
QUERY_PER_MINUTE=60 docker compose up -d --wait api worker
curl --fail --retry 10 --retry-connrefused http://127.0.0.1:8000/api/v1/ready
make eval
docker compose up --build -d --wait api web
```

The final command restores the quota configured in `.env` and rebuilds the API with the updated report. The Markdown report generated by `make eval` stays local.

## Operations and limitations

The demo binds to loopback. Run `docker compose down` to stop it. Adding `-v` permanently erases the demo PDFs, workspaces, and vectors. Save any PDFs you need before resetting the volumes.

Deleting a document removes it from new retrieval immediately. The worker retries file cleanup if deletion fails. Previously returned answers remain in the browser's in-memory history until it disconnects or reloads. Workspace tokens cannot be recovered.

Local matching can miss paraphrases or return weak evidence. Verify answers against cited pages. The app indexes selectable text and has no OCR. Encrypted and malformed PDFs fail indexing. The demo access key and workspace tokens are designed for local use.
