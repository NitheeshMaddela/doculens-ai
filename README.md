# DocuLens AI

DocuLens AI is a private local workspace for searching text-readable PDFs and checking answers against the source. Upload a PDF or load five original synthetic samples, then ask a question and open a citation to see the exact page. The default mode uses local vectors and extractive answers; it needs no model key.

## Run locally

Requirements: Docker with Compose v2.24+ and free loopback ports 3000, 8000 and 5434.

```sh
cp .env.example .env
docker compose up --build -d --wait
curl --fail http://127.0.0.1:8000/api/v1/ready
```

Open [localhost:3000](http://localhost:3000), connect using `DEMO_ACCESS_KEY` (local default `doculens-local`), and select **Load synthetic samples**. Once indexed, choose `cancellation-policy.pdf` as the document scope and ask **What is the cancellation notice period?** Open its citation to page 2. For an unsupported case, ask **What is the payroll tax ID?**

- **Implemented:** private workspaces, polling-based indexing status, durable ingestion and retry, exact pgvector search, cited answers, search-only mode, secure page previews, original PDF download, deletion, and evaluation.
- **Optional:** OpenAI embeddings and structured answer generation. Set `PROVIDER=openai`, `OPENAI_API_KEY`, `EMBEDDING_MODEL`, and `ANSWER_MODEL` in `.env`, then recreate the API and worker. Delete and re-upload existing PDFs to index under the new embedding profile. Hosted inference receives excerpts and questions; use synthetic data for this demo. No live API test was performed.
- **Out of scope:** OCR, streaming, persisted chat history, hosted identity or enterprise compliance.

FastAPI exposes [OpenAPI docs](http://localhost:8000/docs). The TypeScript client uses schemas generated by `make contracts`. The [architecture diagram](portfolio/architecture.svg) and [ADRs](docs/adr/) explain the storage, retrieval, authentication, and worker choices.

## Development and evidence

Install Python 3.12+, uv, and Node 22+; run `uv sync --locked`, `npm --prefix apps/web ci`, and `cd apps/web && npx playwright install chromium` (run the remaining commands from the repository root). Use the Compose stack above for checks that need the DB or browser app.

```sh
make lint typecheck test
docker compose exec -T db createdb -U doculens doculens_test  # one-time
TEST_DATABASE_URL=postgresql+psycopg://doculens:doculens-local@127.0.0.1:5434/doculens_test make integration-test
make e2e
QUERY_PER_MINUTE=60 docker compose up -d --wait --no-build api worker
make eval
docker compose up --build -d --wait api web
make screenshots
```

Use a disposable database ending in `_test`; the integration suite applies and rolls back its migrations. `make eval` needs a query quota of at least 34/minute for this dataset. Rebuild the API image after evaluation so the UI serves the latest report. The next Compose command without the override restores the default quota. `make seed` creates a separately authenticated workspace and saves its token under ignored `.data/`. `make migrate` applies migrations; `make fixtures` regenerates the PDFs.

See [evaluation](reports/evaluation.md), [test evidence](reports/test-summary.md), [security checks](reports/security-checks.md), and [portfolio case study](portfolio/CASE-STUDY-TEMPLATE.md).

## Operations and limitations

The demo is bound to loopback. Use `docker compose down` to stop it; adding `-v` permanently erases all demo PDFs, sessions and vectors. Lost browser tokens cannot be recovered. In local usage, compare PDF UUID filenames to database document IDs during maintenance and take a backup before removing orphan files. Do not share this instance over the internet as-is: hosted use needs stronger identity, retention, rate limits at the edge, malware handling, TLS, secret rotation and operator monitoring. A proxy should apply a request body limit at or below the configured budget.

Deletion removes a document and its vectors from new retrieval immediately. The worker retries private file removal. Existing answers already returned to a browser can remain in its in-memory history until it disconnects or reloads. Logs record request IDs, counts and stage timings; no chat history is persisted. Local lexical matching can miss paraphrases and return weak evidence; review the original page. Scanned, malformed and encrypted PDFs are not indexed.
